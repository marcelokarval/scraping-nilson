# Fase 1.1: Setup do Projeto

**Status**: `[🔄]` Em Andamento

---

### 🎯 Objetivo

Definir a stack tecnológica e criar a estrutura de arquivos inicial para o projeto de scraping.

### 📋 Tarefas Técnicas

- [ ] **Definir Stack Tecnológica:**
  - [ ] Linguagem: Python
  - [ ] Framework de Scraping: Scrapy
  - [ ] Browser Automation: Playwright (para páginas com JavaScript)
  - [ ] Banco de Dados: PostgreSQL

- [ ] **Criar Arquivo de Projeto:**
  - [ ] Criar e configurar o `pyproject.toml` com as dependências iniciais (Scrapy, Playwright, psycopg2-binary).

- [ ] **Configurar Ambiente Virtual:**
  - [ ] Documentar no `README.md` principal os passos para criar um ambiente virtual (`python -m venv .venv`) e instalar as dependências (`pip install -e .`).

- [ ] **Estrutura de Pastas:**
  - [ ] Criar a estrutura de pastas inicial do projeto Scrapy (ex: `scrapy_app/`)
